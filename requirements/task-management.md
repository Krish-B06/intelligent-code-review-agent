# Task Management Requirements

## Requirements

1. Users can create tasks.
2. A task must have a non-empty title.
3. Only the task owner can modify a task.
4. Completed tasks must not be deleted.

## Acceptance Criteria

- Empty task titles must be rejected.
- A non-owner must not be able to complete or delete a task.
- A completed task must remain available for reporting/history.
- Meaningful negative scenarios should have test coverage.
